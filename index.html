wordpress.org / museum

Three ways to see a history

WordPress releases from 2003 to today, rendered as three interactive experiences. Pick a door.

Experience I

Desktop Museum

Boot into an early-2000s desktop where every version is a shortcut, the Start menu is a time machine, and the taskbar keeps ticking.
Experience II

Release Player

Every release is a track. Cue up 2003, follow the timeline, and boot any version in WordPress Playground.
Experience III

Kubrick Weblog

Every release is a post in a period-inspired weblog, complete with archives, comments, and an interactive wp-admin facade.
Each experience can launch releases with WordPress Playground.
